# Apsara Wallet — product image sources

Repository: https://github.com/RithyBondeth/Apsara-Wallet-Web

Original published store panels, preserved in their existing design.

Feature copy is based on the repository's public README captured on 2026-11-10. Diagrams are explanatory graphics, not screenshots or performance claims. Original captures are copied into source/assets and remain unchanged. Wallet's feature images reuse its original store panels.

## Editable assets

The original overview capture, logo, and any additional product captures are included unchanged under `source/assets`. Open `source/hero.html` or the feature HTML files to review the standalone layouts. The bundled font license is in `source/assets/FONT-LICENSE.txt`.

Final hero export: 2400 × 1350 PNG (1200 × 675 CSS pixels at 2×).
Final feature exports: 1080 × 1440 PNG (540 × 720 CSS pixels at 2×).
Wallet's final feature exports preserve the original store panels at their native dimensions; its feature HTML is an alternate concept rather than the source of those preserved PNGs.

No application code or existing screenshots are replaced by this kit.
