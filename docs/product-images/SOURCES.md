# Apsara Wallet product artwork

The personal finance editorial layout draws its palette from the product screenshots.
Open the HTML files in `source/` to edit the artwork. Ubuntu is used for English and Kantumruy Pro for Khmer. Font licenses are included.

The artwork uses original project logos and interface captures. Workflow graphics illustrate the product's documented capabilities.

Repository: https://github.com/RithyBondeth/Apsara-Wallet-Web

Original published store panels, preserved in their existing design.

The mobile panels use the Flutter project's wallet, budget, and savings goal test captures.
